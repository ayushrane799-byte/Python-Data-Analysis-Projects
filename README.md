# Python-Data-Analysis-Projects

Diwali Sales Analysis

Project Overview

This project uses Python to perform exploratory data analysis (EDA) on Diwali sales data. The objective is to understand customer demographics, regional sales patterns, occupation-wise purchasing trends, and product-category performance through data cleaning, aggregation, and visualisation.

The analysis uses Pandas for data manipulation and Python visualisation libraries to identify patterns in the available dataset.

Objectives

Clean and prepare the dataset for analysis.

Explore customer demographics, including gender and age groups.

Compare order volumes and sales across states.

Examine sales patterns across customer occupations.

Identify product categories with higher recorded sales.

Analyse product IDs by order volume.

Translate descriptive findings into potential business questions about customer segmentation and sales performance.

Tools and Technologies

Python — Data analysis and scripting

Pandas — Data cleaning, grouping, aggregation, and manipulation

NumPy — Numerical operations

Matplotlib — Data visualisation

Seaborn — Statistical visualisation, if used in the notebook

Key Business Findings

The notebook explores several descriptive patterns:

Customer demographics: Age-group sales are compared, with the notebook highlighting the 26–35 age group. Gender-wise record counts are also examined.

Geographic performance: State-level order counts and sales amounts are aggregated to compare regional performance.

Occupation: Sales amounts are compared across occupations, with IT, Aviation, and Healthcare highlighted in the notebook's initial interpretation.

Product categories: Food, Clothing, and Electronics are highlighted in the notebook's conclusions and examined through category-level sales aggregation.

Product-level performance: Product IDs are ranked by recorded order volumes to identify products with higher observed counts.

These findings are descriptive and should be interpreted in the context of the dataset. The analysis does not independently establish why customers purchase particular products or prove that one demographic group is more likely to buy than another.

Disclaimer

This project is intended for educational purposes and demonstrates exploratory data analysis using Python. The findings reflect the available dataset and should not be interpreted as causal conclusions or definitive evidence of customer purchasing behaviour.
